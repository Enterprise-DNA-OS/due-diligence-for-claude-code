# Why these records do not need an editing screen

A deal lead spends the week chasing request owners, reviewing evidence, discussing risks and preparing the decision pack. These are database questions and recorded decisions. The CLI performs those actions. The coding agent reads the same records and explains them.

`npm run view` writes private read-only HTML, with no web server or action buttons. `npm run docs` writes decision packs and handover plans. Original files remain in separately controlled storage.

This free base is an operator-managed diligence register. It does not supply a mobile app, collaborative document viewer, offline sync, drag-and-drop file room, watermarking, electronic signatures, hosted identity or external party permissions. A screen gives distributed participants a place to upload and work together; the base does not. Enterprise DNA scopes that shared workflow and access enforcement into a customer's installed version. Do not expose the local database or generated documents publicly.
